# Phase F Implementation Plan: Pilotage & Automation Avancée

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Étendre les capacités du KNIME CLI avec une interface de pilotage visuelle, une analyse de lignage des données, des webhooks d'automatisation et une couverture de tests d'intégration complète.

**Architecture:** 
- **Dashboard** : Page web unique (SPA) servie par la commande `live` via Express, affichant l'état du workflow en temps réel.
- **Lignage** : Moteur d'analyse exploitant les `connections` extraites du XML pour reconstruire le cheminement des données.
- **Webhooks** : Système de notification HTTP déclenché lors des phases de cycle de vie du workflow (`run`).
- **Tests** : Suite de tests "Black Box" validant les commandes du CLI compilé.

**Tech Stack:** TypeScript, Node.js, Express, fast-xml-parser, Jest.
