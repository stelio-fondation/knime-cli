# Phase E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implémenter l'export des métadonnées au format JSON et la génération d'un rapport de Diff Graphique (HTML) pour le KNIME CLI.

**Architecture:** 
1. **Export JSON:** Ajout d'une option `--json` et `--out <fichier>` à la commande `knime info`. Si `--json` est utilisé, la sortie console standard est remplacée par le JSON brut, ou sauvegardée dans le fichier spécifié par `--out`.
2. **Diff Graphique:** Ajout d'une option `--html <fichier>` à la commande `knime diff`. Si elle est fournie, le CLI générera un fichier HTML avec un tableau stylisé présentant les différences (nœuds et variables).

**Tech Stack:** TypeScript, Commander.js, fs (Node.js).

---
