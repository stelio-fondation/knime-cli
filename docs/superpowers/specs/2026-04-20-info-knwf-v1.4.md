# Spécification du Design : Commande info v1.4 (KNWF Support)

Ce document définit l'ajout du support des fichiers `.knwf` (archives ZIP) dans la commande `info`.

## Objectifs
- Lire les métadonnées KNIME directement depuis un fichier exporté `.knwf`.
- Ne pas extraire l'archive sur le disque (lecture en mémoire).
- Maintenir la compatibilité avec l'affichage des nœuds.

## 1. Dépendances
- `adm-zip` : Pour la manipulation des archives ZIP.

## 2. Logique de traitement ZIP
### Localisation du fichier de métadonnées
Un fichier `.knwf` peut contenir le workflow à la racine ou dans un sous-dossier nommé selon le workflow.
Le CLI cherchera de manière récursive ou via un filtre toute entrée se terminant par `/workflow.knime` ou égale à `workflow.knime`.

### Extraction
Le contenu sera extrait via `zip.readAsText(entry)`.

## 3. Refactorisation du Parser
Le code de parsing XML et d'affichage des nœuds sera déplacé dans une fonction utilitaire `parseKnimeXml(xmlData: string)` pour éviter la duplication entre le mode dossier et le mode archive.

## Auto-Review
- [x] Gestion des archives corrompues ou sans fichier `workflow.knime`.
- [x] Performance : `adm-zip` charge l'index de l'archive sans décompresser tout le contenu.
