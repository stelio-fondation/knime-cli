# 📚 KNIME Knowledge Resources

Ce document sert de base de connaissance pour l'agent IA afin d'accéder à la documentation la plus récente et aux standards KNIME.

## 🔍 Sources de Vérité (Live)
Avant toute recommandation, consultez ces ressources :

- **[KNIME Hub](https://hub.knime.com/)** : La source principale pour chercher des nœuds, des composants et des exemples de workflows.
- **[KNIME Documentation Official](https://docs.knime.com/)** : Guides d'installation, de configuration et d'utilisation avancée.
- **[KNIME Forum](https://forum.knime.com/)** : Solutions aux erreurs communes et discussions techniques.
- **[Node Guide](https://nodeguide.knime.com/)** : Détails techniques sur chaque nœud individuel.

## 🛠 API & Développement
- **[KNIME Server REST API](https://docs.knime.com/latest/server_rest_api_introduction/index.html)** : Référence pour les appels API gérés par le CLI.
- **[Batch Executor Guide](https://docs.knime.com/latest/analytics_platform_batch_execution_guide/index.html)** : Paramètres avancés pour la commande `knime run`.

## 📈 Patterns de recherche recommandés pour l'IA

2. "KNIME REST API execute workflow with parameters"
3. "Optimize KNIME workflow performance for large datasets"
